A horizontal pill

The vertical pill keeps account switching in a drawer you open with a separate button. The earlier horizontal pill showed the account's name in full with its state dot and a chevron, and the list dropped from that, so the thing that says what you are tracking is the thing that changes it. These bring that back in today's look: the same soft tints, ring, halo and lights, 72 tall, with the clock still opening the dashboard. Each is shown in every state, and with the list open.

What it changes

Switching account becomes the account name itself, with no separate button, and the live dot and full name are always in view. Against that, the pill is wider (about 390 to 520 by 72, against 72 by 316), so it takes more of a screen's width and less of its height.

What it costs

The vertical pill and the dashboard's rail share one column, so one turns into the other with nothing moving. A horizontal pill would not match the rail, so opening the dashboard would change shape. It would be a setting beside the vertical one, as the old layouts were.

Questions

Is the full name worth the width (A and B) or is C enough? Should the dot show the state, as drawn, or the account's own colour? Should the break stay a tile, or move into the list? Nothing is built.
