Sizes and places

The horizontal pill has the same ring, halo, lights and soft tints, and is drawn at the same scale on each screen. Switching shape keeps the pill's top left corner where it is, and Reset position puts either at the top right.

The dashboard

Opening the dashboard from either pill opens it where the pill was. The dashboard's rail stays vertical, so a horizontal pill changes shape when it opens, which the vertical one does not.
