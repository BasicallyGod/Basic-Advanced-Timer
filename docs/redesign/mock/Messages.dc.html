Messages and errors

Messages float over the lowest part of the workspace, so they never move a button. They say what happened in one sentence and offer the button that helps. They never use red, because red means overtime or a spent budget. An icon and a heavier outline carry the difference instead.

Rules
  • One sentence, in plain words.
  • Say what happened, then offer Undo or Try again.
  • Done is a tick on the accent. Not possible and Needs you are a ring with a mark, never red.
  • The icon always carries the meaning, so colour is never alone.
  • Selection is not a message: it stays in the Selected block card.
